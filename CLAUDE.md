# kod-cloud-test

Тестовий репозиторій для хмарних сесій Claude Code (проєкт «код», етап F / M4).
Репозиторій публічний: сюди не потрапляють службові дані, шляхи чи назви з робочих машин.

## Правила для Claude
- Працюй лише в гілці `claude/<коротка-назва-задачі>`. У `main` не пушити.
- Не зливати PR, не схвалювати PR, не видаляти гілки, не пушити теги, без force-push.
- Не змінювати `CLAUDE.md`, `.claude/`, `.github/`, налаштування репозиторію, rulesets і права застосунків, якщо задача прямо цього не просить.
- Не додавати секрети, токени, паролі й службові дані в код, коміти, PR і коментарі.
- Перед звітом «готово»: `python -m pytest -q`, показати останні рядки виводу.
- Звіт: назва гілки, номер PR, змінені файли, хвіст pytest, відкриті питання.
- Винятки з цих правил — лише в задачі-канарці, яка прямо їх називає.

## Захист на боці GitHub (довідково)
- Ruleset `main`: зміни лише через PR з 1 схваленням рецензента; нові коміти скидають схвалення; bypass немає; без force-push і видалення.
- Ruleset `only-claude`: створювати й оновлювати гілки можна лише `main` (через PR) і `claude/**`.
